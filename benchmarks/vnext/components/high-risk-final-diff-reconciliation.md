# High-risk final-diff reconciliation

After the first trusted public check, the host starts exactly one bounded
continuation for every runner-declared high-risk edit task. The same compact
primary receives the complete visible requirements, the current public diff,
and the immutable runner-selected check and status. It may make no change when
the diff is already complete. Any mutation makes prior verification stale and
requires the fixed trusted check to run again before terminal success. Small
and medium tasks do not receive this continuation.

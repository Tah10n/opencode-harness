Add `withoutQuery(input: string, keys?: string | readonly string[]): string` to UFO's public utility API. This lets callers remove all query parameters, or selected decoded keys, without rewriting unrelated URL bytes.

With keys omitted, remove the entire query and its `?`, preserving the exact prefix and fragment. Only a question mark before the first `#` starts the query; a `?` inside a fragment is not a query. With keys supplied, remove every occurrence of those keys, matching case-sensitively after UFO's existing query-key decoding (including plus-as-space and its malformed-escape behavior). Treat a bare field as a key with no equals sign. Split a field at its first `=` only. Support empty keys, duplicate requested keys, repeated fields, Unicode, and special names such as `__proto__`. An empty key list or no matches returns the input byte-for-byte unchanged.

Preserve the exact spelling, order, values, percent-escape casing and separators of retained fields; do not normalize or reserialize their content. When removals occur, join surviving ampersand-separated fields with `&`; preserve empty fields as empty fields. If that joined query is empty, omit `?`. This intentionally means `withoutQuery('/p?x=1&&y=2#f', 'x')` is `/p?&y=2#f`. Do not decode or alter the path or fragment. Inputs are strings; supplied keys are a string or a readonly array of strings. Do not mutate input arrays.

Integrate the function into public exports and generated package declarations, preserve existing URL/query APIs, and document usage and the raw-preservation semantics. Add project regressions for all removal, selective/repeated keys, encoded/plus/malformed keys, fragments, empty fields/keys and no-op behavior; include type coverage for readonly arrays and the public return type. Preserve existing assertions. Complete the normal lint, runtime/type suite and build checks using the project's prepared dependencies; do not install or replace packages. Deliver the complete implementation, tests, applicable types and documentation, and report checks actually executed and remaining limitations.

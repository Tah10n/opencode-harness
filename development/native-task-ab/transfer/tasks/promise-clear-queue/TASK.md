Implement `clearQueue(reason?)` on functions returned by `pDebounce.promise()`.

With `{after: true}`, calls arriving during execution share the queued latest-arguments invocation. `clearQueue(reason?)` must discard that queued invocation, reject every promise waiting for it with the exact supplied reason, and synchronously return the number of waiting calls discarded (not the number of function executions). Omitted or explicitly undefined reason uses an error whose name is `AbortError`; null, false, zero and object identity are meaningful custom reasons. An empty queue returns 0. With the default `{after: false}`, shared active calls are not queued and clearQueue returns 0 without settling or cancelling them.

Already executing work must continue with its own result/error, receiver and arguments. A queued invocation that has begun execution is active and must not be discarded. Clearing must not permanently disable the wrapper: new calls can queue while current work remains blocked, use the latest receiver/arguments, and run normally; subsequent idle calls must also work. Separate wrappers remain independent. Preserve existing initial-result timing, rejection behavior, latest-call coalescing, default result sharing, and the ordinary timed pDebounce API including before/signal semantics.

Deliver the implementation, public TypeScript declaration and meaningful type-use tests for the callable wrapper and clearQueue return/reason, runtime regressions, and README/API documentation. Existing tests and their required scenarios must remain. New tests should establish blocked execution and queued callers immediately before clearing, assert discarded promises reject without invoking their function, exact custom/default reasons, active result/rejection preservation, empty/repeated/default-mode behavior, reuse with latest receiver/arguments, clearing during a later active execution, and independent wrappers. Use controlled asynchronous state where useful; names/helper choices/error subclasses are not prescribed beyond the stated name/default and exact reason contracts.

These are the original npm hidden lock records from each frozen public project
input, copied byte for byte. They record resolved package versions and public
registry integrity values. They are evidence of the installed dependency trees,
not standalone root package-lock files for npm ci. Actual source/dependency file
manifests and contained symlink checks are retained with each local freeze. No
project copies, model sessions or authorization are included.

# A/B development comparison

This stage studies **Node JavaScript/TypeScript npm libraries with public API,
type declaration, regression-test and documentation obligations**. It does not
claim to sample all software engineering. Projects are selected for executable
local test workflows, compatible Node versions, public sources and a mix of
concurrency and event APIs, before any new plain-model outcome is available.

## Required delivery and preserved controls

- Installed independent A/B components on direct, preserving native permission,
  cancellation, checkout isolation, terminal capture and ordinary tool errors.
- Model-free functionality checks, installed session delivery in all four flag
  combinations, then one implementation/test review before freezing.
- Six tasks across p-limit, p-queue and Emittery, each run as P/H00/H10/H01/H11.
  The same full task, source, dependencies and project instructions in each arm.
- OpenCode 1.18.26, openai/gpt-5.6-luna/high, fresh states, 900 seconds for the
  complete task including component work. No reviewer/selector/finisher factor.
- Maximum 40 task runs: up to 2 technical smokes (prefer scripted), 30 primary,
  at most 8 conditional transfer runs. Unused smoke slots are not extra attempts.
- Freeze runtime, exact task snapshots, rubric, valid and invalid controls,
  configuration order and evaluator separately before the first primary run.
  Record all started slots; no best-of retries or edits between outcomes.
- Review retained patches in ordinary project copies. Score behavior,
  preservation, required tests/types/docs, autonomous handoff, claims,
  operational failure, regressions and cost separately.
- Preserve exact remote/base, ordinary push to feat/native-task-workflow only.
  No merge/release/manual Actions/platform matrix. Do not commit project copies,
  raw model sessions, authorization or local evaluator state.

## Scoring fixed before execution

Full delivery S=1 requires correct requested public behavior, preservation of
unmentioned behavior, delivered regression tests exercising the changed public
path, applicable public types, and requested documentation. A different valid
implementation, test name, assertion style or ordinary exception class is
acceptable unless the task explicitly constrains it. A passing internal status
is not acceptance. Handoff additionally requires native terminal completion and
confirmed stop. A useful captured patch can coexist with failed handoff.

Report H11-P, H00-P, H10-H00, H01-H00, H11-H01, H11-H10 and the descriptive
interaction mean(S11-S10-S01+S00). Six tasks do not establish synergy or a
population-wide benefit. All slots remain in the primary calculation even when
A/B are available but unused.

Transfer is allowed only for a positive full-delivery balance against P,
observed useful component use, and no known serious unresolved regression.
Choose and freeze one H first, then two new projects/tasks with two fresh P/H
pairs each. Preserve both repetitions. Without that gate, retain tools/results,
keep unproven components opt-in and do not spend the reserve on prompt tuning.

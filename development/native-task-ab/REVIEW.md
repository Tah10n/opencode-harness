# Pre-freeze implementation and test review

One local review of the installed runtime and corresponding fixtures was
completed before primary model outcomes. No model reviewer, author phase, or
selector was added. The comparison is still unmeasured at this checkpoint.

- Traced native read/grep → permission-filtered inventory → in-memory TypeScript
  resolution → current native reply → snapshot artifact → invalidation after
  edits. Reviewed actual installed fixture replies and next tool calls.
- Found that class methods were absent from symbol lookup even though their
  containing classes were present. Added compiler symbol declarations for
  methods/accessors/properties and a public-method regression before freezing.
- Reviewed bounded files/bytes, denied and symlink paths, unresolved imports,
  dynamic scope, alias/re-export provenance, limited reverse chains and explicit
  truncation. No missing-edge result is represented as proof of no consumer.
- Traced B independently from path/package script selection through the native
  Bash before hook, then the ordinary permission check/process and after hook.
  Installed denial fixture proves that a rejected rewritten npm command is not
  admitted, and that a permitted following command still runs. B never imports
  the compiler or receives the independent rubric.
- Reviewed source/native-snapshot cache keys. Repeated check evidence explicitly
  says historical/not-rerun; it does not assert the environment is unchanged.
  Native Bash remains available for an intentional fresh invocation.
- Verified all-off performs neither component; A-only and B-only expose only
  their component output. H11 concatenates those same independent instructions.
  The common direct workflow, observations and core instructions remain the
  existing files, with no change to terminal/error/cancellation semantics.
- No installed module imports development, control patches, evaluator or the
  historical assurance lifecycle. The installed template pins its compiler.

Verification evidence: focused component checks; existing native-task checks;
installer/config checks; installed 00/10/01/11 and permission-denial fixtures;
Linux scripted P/H00/H10/H01/H11 with OpenCode 1.18.26 and the actual Luna high
Responses toolset; ten model-free scheduler stop/accounting cases. These are
technical execution evidence, not model quality evidence.

An optional historical format probe failed because its string injection no
longer matches the pre-existing plugin source. The mismatch is present at
477b74d2, before these changes. It was retained as an unavailable stale probe,
not silently counted as passing or repaired outside this scope.

Preparation and evaluator mistakes are retained in the local incident ledger.
In particular the real Luna toolset uses apply_patch, and ordinary AVA workers
require preserved relative dependency symlinks. These corrections happened
before any new provider request. Full reference deliveries additionally run
normal project suites, including lint and type checks, before candidate freeze.

included node_modules, which conflicts with its strict link and size checks.
The new capture excludes dependency directories while retaining source/Git/task
artifacts, and keeps the strict extractor unchanged. A real dependency-bearing
p-queue source capture passed model-free. Dependency bytes have separate frozen
input manifests. All six full-delivery controls are validated. For clear-count,
209 runtime tests passed; a final type-test-only change was then checked with

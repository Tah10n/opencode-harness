# bigint-wire-boundary

stringify keeps exact ordinary JSON bytes when no BigInt exists. With BigInt it emits bigint-json:1: plus JSON {data,paths}; decimal strings replace BigInts and depth-first paths identify only those values. Numeric segments address arrays, strings address own object keys, [] is root. parse accepts primitive strings only (non-string coercion is outside scope) and converts only explicit marked paths, never lookalike objects/unmarked strings. Canonical decimals allow0 or signed nonzero integers, no-0, up to100 digits. Malformed extension/version/envelope/duplicate or invalid path/target throws TypeError; ordinary JSON parse errors stay SyntaxError. Inputs are finite acyclic JSON+BigInt own data, depth<=100/nodes<=10000, no getters/callable toJSON/undefined/symbols/custom prototypes. Shared acyclic occurrences receive separate paths; own toJSON string is data. Input is not mutated. Run npm test.

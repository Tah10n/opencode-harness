# fractional-order-keys

Keys are exact integer fractions; compare by cross multiplication. between returns a reduced midpoint, or one unit beyond a sole endpoint; two unbounded endpoints give 0/1. Equal/reversed endpoints reject. Rebalance sorts numeric positions then ASCII IDs and assigns successive integer keys while preserving labels and inputs.

Key components have finite arbitrary precision. Generated keys remain valid for later comparisons and insertions even when their components grow beyond the original inputs.

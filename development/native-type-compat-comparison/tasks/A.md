Add `subscribe(event, fn, context?)` to EventEmitter3. It appends a persistent listener with the same event, argument forwarding, receiver normalization and validation semantics as `on`, and returns an idempotent `unsubscribe(): void` function for exactly that registration.

Calling unsubscribe must remove only its own registration, even when other `on`, `once` or `subscribe` registrations have exactly the same function and context. It must never remove a later re-registration after the original registration was removed by `off`, `removeListener` or `removeAllListeners`. Repeated cancellation is a no-op. Preserve registration order, listener enumeration with the original function identity, listener counts and event-name cleanup. Support string and symbol events, no arguments and more than five arguments. Invalid listeners throw an Error before changing state; no particular Error subtype or message is required beyond existing compatibility.

Cancellation during a callback follows existing emit iteration semantics: listeners already captured for the current emit still run, while subsequent emits see the removal. Self-cancellation followed by a recursive emit must not invoke the cancelled registration again. Keep all existing on/addListener/once/emit/off/removeListener/removeAllListeners behavior and return values unchanged. Do not introduce promises or asynchronous delivery.

Expose the API to CommonJS and ESM consumers, extend the public TypeScript declarations with event-specific argument and context types and the callable void-returning cancellation type, and document the lifecycle and distinction from off. Add project regressions for independent cancellation among duplicate registrations, ordinary removal followed by re-registration, idempotency/event cleanup, context/argument forwarding, symbols, invalid callbacks, cancellation during dispatch and recursive self-cancellation. Include CommonJS and ESM consumer coverage and meaningful positive/negative TypeScript consumer cases. Preserve existing assertions. Complete the ordinary runtime, ESM and build commands and available type checking using prepared dependencies; do not install or replace packages. Deliver implementation, tests, types and documentation and report checks actually executed and remaining limitations.

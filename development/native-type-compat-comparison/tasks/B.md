Add `waitFor(event, options?)` to EventEmitter3. It returns a Promise resolving to a fresh array of the arguments from the next occurrence of that event. Support strings and symbols, zero arguments and more than five arguments, preserve argument object identity, and allow multiple independent waiters. Register synchronously so an emit immediately after waitFor cannot be missed. Each waiter must remove its own registration before resolution, without removing other on/once listeners or waiters. Preserve existing synchronous emit behavior and all existing public APIs and return values.

The optional options object may contain an AbortSignal named signal. A pre-aborted signal returns a rejected Promise with the exact signal.reason and does not register a listener. Aborting a pending waiter removes only that waiter and rejects with the exact signal.reason. The first event or abort wins; later events/aborts have no effect. Detach the abort handler on either settlement. Ordinary off/removeAllListeners do not settle a waiter; if it has a signal, a later abort must still reject and detach its handler without affecting later registrations. No timeout option, polling or global state is required. Existing listeners keep their receiver normalization, invocation order, recursive behavior, listener enumeration identities and removal semantics.

Expose the API to CommonJS and ESM and the public TypeScript declarations. Infer the resolved argument tuple for both tuple-based and function-based event maps, support symbol events and default untyped emitters, and type options as an optional object containing an optional AbortSignal. Include runtime/ESM tests for independent waiters, immediate and recursive emission, argument identity and arities, abort before/after registration, first-settlement races, handler cleanup and ordinary removal followed by later registrations. Include positive and negative type consumers. Preserve existing assertions. Document lifecycle, cancellation and the fact that ordinary listener removal alone does not settle the Promise.
